RPT 상품프로필조회 모바일 v3.7

수정 내용
- 검색창, 검색 버튼, 초기화 버튼 높이를 이전 대비 약 60%로 축소
- 상품 이미지는 기존 크기 유지
- 상품 정보 텍스트를 약 90%로 축소
- 상품 정보 행 간격 축소
- 상세페이지 열기 버튼 높이를 약 80%로 축소
- 그룹 상품 각 칸 높이를 약 80%로 축소
- 업로드한 강아지 이미지를 PWA 앱 아이콘으로 적용
- 아이콘 파일명, manifest ID, start_url, 캐시 버전을 모두 v3.7로 변경하여 이전 아이콘 캐시 우회

업로드 방법
- 압축을 풀고 GitHub 저장소 루트에 모든 파일을 덮어쓰기
- 홈 화면에 설치된 기존 앱은 삭제
- 브라우저에서 새 페이지를 한 번 연 뒤 다시 홈 화면에 설치
