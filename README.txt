RPT 상품프로필조회 모바일 v3

적용 내용
- 전체 UI 약 30~40% 확대
- 제목 30px
- 검색창/검색/초기화 버튼 높이 56px
- 상품 정보 글자 및 항목명 확대
- 상세페이지 버튼 높이 56px
- 같은 그룹 상품 카드 최소 높이 78px
- 선택된 그룹 상품 강조
- 그룹 상품 개수 표시
- 그룹 상품 선택 시 이미지와 정보 즉시 변경
- 상품 이미지는 1:1 비율 유지
- 그룹 상품은 상품 정보 아래쪽에 표시
- 작은 휴대폰에서도 화면 너비에 맞춰 자동 조절

업로드 위치
https://github.com/nu9ri/rpt-product-profile

저장소 루트에 다음 파일을 덮어쓰기:
- index.html
- manifest.json
- service-worker.js
- icon.svg

기존 products.json 및 images 폴더는 그대로 사용합니다.
