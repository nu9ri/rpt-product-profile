RPT 상품프로필조회 모바일 v4

수정 내용
- 앱 아이콘 복구
- Android PWA용 192x192, 512x512 PNG 아이콘 추가
- iPhone 홈 화면용 apple-touch-icon 추가
- 제목, 검색창, 버튼, 상품정보, 그룹 카드 대폭 확대
- 작은 화면에서도 버튼이 잘리지 않도록 모바일 폭 조정
- 기존 products.json과 images 폴더는 그대로 사용

GitHub 저장소 루트에 이 압축파일의 모든 파일을 덮어쓰세요.

중요:
기존 홈 화면 앱 아이콘이 계속 안 보이면
1. 기존에 설치한 홈 화면 앱을 삭제
2. 브라우저 캐시 새로고침
3. 다시 '홈 화면에 추가' 또는 앱 설치
서비스워커와 앱 아이콘은 이전 캐시가 남을 수 있습니다.
